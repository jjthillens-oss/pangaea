## Open owner decisions

1. **The player-facing name** (also open in `docs/DECISIONS.md`). Existing Steam games named *Pangea* make the plain
   name hard to find; a distinctive subtitle is recommended.
2. **Release model:** Coming Soon page first, then full release or Early Access.
3. **Individual or company** for the Steamworks account.
4. **AI-content disclosure wording** for Steam's content survey.

## Rules

No other game's names, art, music or footage anywhere in store material. Copy describes only what the build contains.
Capsules carry art and the title only. Screenshots and trailers use real gameplay.
