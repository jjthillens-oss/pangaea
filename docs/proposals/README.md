# Era proposals - PROPOSED

Every link here is an unapproved design proposal. The seven working names, count, order, boundaries, and later-era scopes follow GENESIS Bible v0.1 section 4; they are **PROPOSED**, not implementation commitments. The microscopic first playable is described in the Bible and current milestone docs, not in a separate proposal here. These documents do not alter the save schema, art pipeline, or milestone scope.

## Shared transition contract - PROPOSED

Each handoff requires a demonstrated capability, a survivable destination, an informed player choice, and a pre-transition recoverable checkpoint. The earlier era retains a playable local activity; an earlier adaptation still has a functional consequence; a named historical relationship continues. Changes to persistence, transition transactions, or content scope need separate owner decisions and migration tests. The proposals should be reviewed as connected slices, not as seven independent campaigns.
