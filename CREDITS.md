# Credits for outside work

Pangaea's code and art are original. This file lists the work by other people that the game includes under a
licence that asks for credit. CC0 sources (Poly Haven, ambientCG, Kenney, OpenGameArt) ask for none; they are
logged in the asset records under `assets/records/`.

Anything listed here must also be credited where players can see it (a credits screen, or this file shipped beside
the game) before a build goes public.
