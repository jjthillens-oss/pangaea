# Bush 1 — airy flowering sage

Status: standalone review candidate. This folder is isolated from production scenes. The editable Blender source and Godot GLB are generated by `build.py`.

## Reference contract

The CC0 [sage shrub photograph](provenance.md) supplies observable plant traits, not a mesh template. At a three-quarter game view the silhouette must read as an asymmetrical, wide, airy shrub: several upright stems, a small basal knot, one low outward branch, and gaps through the upper canopy. From the side it must retain depth rather than collapse to a billboard. Near view should reveal slender sage leaves and occasional blue-violet flowers. Gray shape renders are reviewed before color renders. The second bush variant should instead be a denser broadleaf mound without this sparse flowering fan silhouette.

| Gate | Visible criterion |
| --- | --- |
| Shape, gray | Uneven fan; stems branch; open negative space; a low side branch; no obvious single primitive silhouette. |
| Material | Rough, nonmetal gray-brown wood; muted warm sage leaves; sparse blue-violet petals; no emission. |
| Scale | About 1.9 m wide and 1.3 m tall at 1 Blender meter = 1 Godot unit; origin at ground. |
| Export | Godot-importable GLB; ≤2,000 triangles; at most three opaque Principled PBR materials; no procedural nodes or external textures. |
| Review | Matched reference/result sheet; front, side and three-quarter gray/material views; separate Godot import and rendered review. |

The scale is an art assumption for a standalone prop, pending game placement review. The palette follows `docs/art/ART_DIRECTION.md` (“soft life hardens” and warmer living props against the cool habitat). A viewer should identify it by silhouette even without its flower color. Review must inspect actual images; a headless import alone does not clear the visual gate.

## Build and review

Use the local Blender executable with `--background --python build.py`. The script writes the editable `.blend`, GLB, views, and geometry report to this folder. It uses deterministic original geometry and only glTF-compatible Principled BSDF materials. No generated texture is needed because all material channels are constants. After visually inspecting the Blender and isolated Godot views, run `pwsh -File make_sheet.ps1` to assemble the paired sheet.

See [gate report](gate-report.md) for actual measurements and the [isolated Godot recipe](review/README.md) for a repeatable renderer check. Final in-game placement and lighting remain for a later integration review.
